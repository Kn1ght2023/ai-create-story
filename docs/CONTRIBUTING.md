# 贡献指南

## 构建与验证

后端 Go 1.25.1，仅标准库；前端 Vite 5 + Svelte 4，依赖由 package-lock.json 锁定。

```bash
cd frontend
npm ci
npm run build
cd ..
go build ./...
go test ./...
go vet ./...
```

前端构建产物由 main.go 嵌入；frontend/dist 不提交 Git，克隆后须先构建前端。完整构建也可用 task build，开发运行方式见根目录 README。

## 修改约定

- 保持包依赖方向：HTTP → agent → story → 基础包，不引入循环依赖。
- Go 后端不新增第三方依赖；如确有必要，先在变更说明中讨论。
- 新增可见文案同时维护中英文；提示词、系统提示和上下文注入也保持双语一致。
- 保留领域测试、前端自检及独立脚本测试；测试不能依赖个人小说或真实密钥，不默认调用付费 API。
- 配置和进度写入保持原子性；异步任务遵守现有互斥与取消约定。
- 变更行为后更新公开文档，不把未来规划表述为现有功能。
- 上传示例前用合成内容替换用户资料；不可提交密钥、真实模型响应或个人小说。

## 公开服务

当前版本仍是共享状态的个人工具，不具备应用级多用户隔离。部署边界见 [部署文档](DEPLOYMENT.md)。提交说明应包含问题、最终行为和实际执行的验证；未完成的检查说明原因。
